## 📐 Zuhri Formalism (ZF)

**Formula:**
```
ZF(t) = 0.35*ADF + 0.30*CONF + 0.20*Speed + 0.15*Tick

ADF = Auction Distribution Factor
CONF = Confidence (DEC A/B/C)
Speed = Price velocity
Tick = Tick density
```

**States:**
- `ZF > 0.70` → BUY Zone
- `ZF < 0.30` → SELL Zone  
- `0.30-0.70` → WAIT Zone (e.g., AUDUSD 0.70167 WAIT 0.70250)

**DEC Logic:**
- **DEC A:** Strong momentum, high CONF
- **DEC B:** Retrace + exhaustion
- **DEC C:** Counter-trend safety

## ⛏️ Proof-of-Profit (PoP)

**How mining works:**

1. **Trader trades XAUUSD / Forex with EA V21.30**
2. **Oracle verifies performance:**
   - Layer 1: Myfxbook API
   - Layer 2: Broker REST via Chainlink
   - Layer 3: ZK-Proof of trades
3. **Anti-Luck Filter (6 factors):**
   - PF > 1.5
   - Sharpe > 1.2
   - Max consecutive loss < 5
   - Min 50 trades
   - Lot consistency std/mean < 0.30
   - ZF avg > 0.45
4. **If passes → Mint ZFT**
